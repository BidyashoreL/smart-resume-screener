# API Reference

Base URL (local dev): `http://localhost:8000`

Interactive, always-current docs are auto-generated by FastAPI at `/docs`
(Swagger UI) and `/redoc` once the server is running - this file is a
human-readable companion, not a replacement.

All error responses share one shape:

```json
{"error": "CandidateNotFoundError", "detail": "No candidate with id 'candidate_xyz'."}
```

---

## `GET /health`

Liveness check.

**Response `200`**
```json
{"status": "ok", "service": "Smart Resume Screener"}
```

---

## `POST /api/resumes/upload`

Upload a PDF or TXT resume. Extracts text, runs LLM structured extraction,
validates it, and persists the resulting candidate profile.

**Request:** `multipart/form-data` with a single field `file`.

```bash
curl -X POST http://localhost:8000/api/resumes/upload \
  -F "file=@data/sample_resumes/priya_sharma.txt"
```

**Response `201`**
```json
{
  "candidate_id": "candidate_5e005da070",
  "status": "processed",
  "name": "Priya Sharma",
  "warnings": []
}
```

**Errors:** `400` unsupported file type, `413` file too large, `422` text
extraction failed (including `OCR_REQUIRED` for image-only PDFs) or the LLM's
extraction didn't match the candidate schema, `502` the LLM provider itself
failed (timeout, auth error, rate limit).

## `GET /api/resumes/{candidate_id}`

Fetch a stored candidate profile.

**Response `200`**
```json
{
  "candidate_id": "candidate_5e005da070",
  "name": "Priya Sharma",
  "email": "priya.sharma@example.com",
  "profile": { "...": "full CandidateProfile - see README section 8" },
  "created_at": "2026-08-23T18:17:02.123456+00:00"
}
```

**Errors:** `404` if the candidate doesn't exist.

## `POST /api/jobs`

Create a job from a pasted description. Extracts structured requirements via
the LLM and persists them.

**Request**
```json
{
  "description": "We are hiring a Machine Learning Engineer. Required: Python, Machine Learning, PyTorch. Preferred: Docker, AWS, FastAPI. Minimum 2 years experience. Requires a degree in Computer Science.",
  "title_hint": null
}
```

**Response `201`**
```json
{"job_id": "job_0dad858a24", "status": "created"}
```

**Errors:** `422` if `description` is under 20 characters or the LLM's
extraction didn't match the job schema, `502` LLM provider failure.

## `POST /api/screen`

Screen a batch of candidates against one job. Runs the full hybrid matching +
scoring pipeline for each candidate, persists every result under a shared
`screening_id`, and returns them ranked by overall score, descending.

**Request**
```json
{
  "job_id": "job_0dad858a24",
  "candidate_ids": ["candidate_5e005da070", "candidate_9a1bc2d3e4"]
}
```

**Response `200`**
```json
{
  "screening_id": "screening_5ebd211a5a",
  "job_id": "job_0dad858a24",
  "results": [
    {
      "candidate_id": "candidate_5e005da070",
      "candidate_name": "Priya Sharma",
      "scores": {
        "skill_score": 90.0,
        "experience_score": 100.0,
        "responsibility_score": 90.0,
        "education_score": 100.0,
        "overall_score": 94.0
      },
      "match_band": "Strong Match",
      "recommendation": "SHORTLIST",
      "matched_required_skills": ["Python", "Machine Learning", "PyTorch"],
      "missing_required_skills": [],
      "matched_preferred_skills": ["FastAPI"],
      "missing_preferred_skills": ["Docker", "AWS"],
      "skill_evidence": [
        {"skill": "Python", "required": true, "matched": true, "source": "candidate profile"}
      ],
      "strengths": ["Strong Python/ML background"],
      "weaknesses": ["No AWS evidence"],
      "justification": "Strong fit for the ML engineer role."
    }
  ]
}
```

**Errors:** `404` if `job_id` or any `candidate_id` doesn't exist, `502` if
the LLM matching call fails for a candidate.

---

## `GET /api/screen/{screening_id}`

Retrieve a previously-run screening batch by id (re-ranked from the persisted
rows). `404` if the id doesn't exist.
